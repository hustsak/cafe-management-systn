# Coffee Shop Management System

A desktop application designed to streamline daily coffee shop operations, billing, menu management, and inventory tracking.

---

## Features

- **Order & Billing Management:** Quickly process customer orders and calculate totals.
- **Menu Management:** Add, update, and manage coffee items, snacks, and pricing.
- **Sales & Reports:** Track daily transactions and review sales activity.
- **Inventory Tracking:** Monitor ingredient availability and key stock levels.

---

## Project Structure

```text
Coffee-shop-management-main/
├── bin/          # Precompiled executable and runtime dependencies
├── .idea/        # JetBrains / CLion IDE configuration files
└── .gitignore    # Git ignored files configuration
Requirements
Operating System: Windows 7, 8, 10, or 11 (32-bit or 64-bit)

Development Environment (Optional): CLion, Visual Studio, or any standard C/C++ compiler suite

How to Run
Method 1: Direct Execution
Extract the contents of Coffee-shop-management-main.rar.

Open the bin/ directory.

Ensure all included .dll runtime files remain in the bin/ directory alongside the application executable.

Double-click the .exe file to launch the application.

Method 2: Open in an IDE
Open your IDE (e.g., CLion).

Choose Open Project and select the root Coffee-shop-management-main folder.

Build and launch the target from the IDE interface.
